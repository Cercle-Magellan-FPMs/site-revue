# Revue des Mines 2028

Site Astro de pré-lancement de la prochaine Revue des Mines de la Faculté Polytechnique de Mons, prêt pour un déploiement statique sur Vercel.

## Démarrage

```bash
npm install
npm run dev
```

Déploiement : connecter ce dépôt à Vercel, choisir le framework Astro, commande de construction `npm run build`, dossier de sortie `dist`.

La date exacte, le thème et la billetterie ne sont pas encore annoncés.
